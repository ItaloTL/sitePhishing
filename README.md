##Proposta

Este é um site phishing desenvolvido em um laboratório controlado afins didáticos de compreender questões de segurança na internet e aprimorar a capacidade de desenvolvimento dos alunos. Através de uma cópia idêntica da tela de login da Microsoft, onde ao logar os dados do usuário serão armazenados no banco de dados e o mesmo será direcionado para a página oficial.
